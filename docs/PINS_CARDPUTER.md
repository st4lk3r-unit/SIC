# Cardputer pins (defaults via `platformio.ini`)

- I2C: `I2C_SDA_PIN=41`, `I2C_SCL_PIN=42`
- MIC (PDM): `MIC_DATA=46`, `MIC_CLK=43`
- IR TX: `IR_TX_PIN=44`
- Battery ADC: `BAT_ADC_PIN=10`, `BAT_DIV_K=2.0`

Keyboard (74HC138):
```
KBD_EN=2  KBD_A0=16  KBD_A1=17  KBD_A2=18
KBD_IN1=15 KBD_IN2=3 KBD_IN3=4 KBD_IN4=5 KBD_IN5=6 KBD_IN6=7 KBD_IN7=0xFF
KBD_PULL=UP KBD_ACTIVE_LOW=1 KBD_DEBOUNCE_MS=20
KBD_IN_PERM={0,1,2,3,4,5,6}  KBD_INPUT_SWAP_56=0  KBD_BANK_FLIP=0
```
